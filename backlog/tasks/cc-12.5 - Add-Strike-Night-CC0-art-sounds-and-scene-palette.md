## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Verify: pnpm check:style

Sprites: 5 CC0 Kenney Roguelike Indoors furniture tiles (bench/chair/table/picture/plant) recoloured onto alley, plus 6 hand-authored palette-exact sprites (ball 4-frame spritesheet, pin, ceiling-light, target-arrow, lane-plank tile) for everything the game spec's CC0 shortlist marks 'drawn from scratch'. Wired into games/strike-night/src/host/world.ts, replacing every placeholder primitive (ball, pins, bench, ceiling lights, target arrows, lane/gutter boards). Lane/gutters use a Graphics plank fill with perspective-correct converging board-seam lines, not a tiled+masked TileSprite: Phaser 4's GeometryMask only clips in the Canvas renderer (Mask.setMask's own console warning), so a masked TileSprite silently renders unmasked under WebGL (the production AUTO renderer) -- found and fixed during verify, see world.ts's plankSurface(). Also fixed games/strike-night/test/host/scene.browser.test.ts's waitForRunning: it only awaited Promise.resolve() (a microtask), which never gives a real Image.onload (a task-queue callback) a turn once the scene got a real preload(); now awaits a setTimeout(0) turn instead -- all 3 pre-existing browser tests plus the new sprite/world code depend on this. Sounds: 34 real CC0 files (Kenney Impact/Interface/Music-Jingles packs, OpenGameArt qubodup's Bowling Ball Rolling, iamoneabe's Funky Menu Loop re-encoded 741KB->296KB with ffmpeg, TinyWorlds' Happy Adventure Loop backup) in assets/sounds/, matching quick-draw's/target-range's precedent of shipping credited sound assets with no playback wiring yet (cues.ts already documents 'until then nothing listens'). Funky Menu Loop's tempo (104 BPM per its own ID3 tag, ~100 BPM independently via aubio) is below the spec's 110-130 BPM ask -- shipped anyway and flagged transparently in CREDITS.md since no other CC0 candidate fit better. Host per-game chunk: 54.88 KB -> 57.33 KB gzip (60 KB budget), 2.67 KB headroom left. Not included in this story (flagged as follow-ups in CREDITS.md): sweep bar / ball return props, and sound-playback wiring.

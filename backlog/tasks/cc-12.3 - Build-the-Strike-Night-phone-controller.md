## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Verify: pnpm check && pnpm test

CC-5.9/CC-12.3 note: no recorded real-device bowling swing trace exists in this environment (no phone hardware). Used documented synthetic traces (@couchcade/motion/sensors createFakeAdapter + a pure-rotation MotionSample generator, matching the pattern packages/motion/test and games/target-range/test/controller/motion.ts already use) for every motion-mode test. Recording a real trace per platform (iOS/Android) stays a follow-up outside this environment's reach.

CI fix: adding the jsdom 'controller' vitest project pushed the pre-existing, CC-12.2-owned Planck.js contract-test property check (packages/game-sdk/testing/contract.ts, hardcoded 30s timeout) over its limit on CI's 2-core runner (30-38s observed over 2 reproducible failed runs). Capped the controller project to maxWorkers:1 in games/strike-night/vitest.config.ts, leaving the node project more headroom; confirmed green on the next CI run (test: 2m51s pass, e2e: pass). Follow-up worth a look: the hardcoded 30s hasn't got per-game slack, and strike-night's rules are the heaviest of the 3 shipped games -- future games with similarly heavy physics may need the same treatment or a bump to that shared timeout.
<!-- SECTION:NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Built games/strike-night/src/controller/: Controller.vue wires a CcDragSlider move bar and a CcBigAction grip through the game's InputChannel (move/grip via stream, bowl via fire). bowl.ts drives createSwingDetector (motion) and createSwingSwipe (touch), both emitOn: release, falling back to touch whenever motion is undefined, touch-only, or stops mid-game. present.ts is a pure function covering every spec screen (sn-watch, sn-next, sn-bowl roll 1/2, gripping/noSwing/away locals, sn-result with every mark) with copy under 40 chars. Added @couchcade/motion as a dependency and a jsdom controller test project (vitest.config.ts); 98 new tests cover AC1-4, all inputs validated against inputSchema. Reviewer (sonnet) passed round 1 with two advisory findings: (1) no real-device swing trace exists in this environment -- used documented synthetic traces (createFakeAdapter), consistent with CC-5.9's note; recording real traces stays a follow-up. (2) a motion-to-touch switch mid-grip silently drops the in-progress swing instead of carrying it over -- narrow edge case, not fixed, flagged for the owner.

BLOCKED at Verify (2026-09-18): rules/state/tests are complete and green
(pnpm check, pnpm --filter @couchcade/game-strike-night test: 42/42 pass, pnpm check:deps:
clean), but the repo-wide `pnpm test` fails in tooling/budgets: "Host platform JS 482.63 KB /
450.00 KB" (over by ~32 KB), because apps/host/src/runtime/games.ts eagerly globs every game's
src/index.ts (`import.meta.glob(..., { eager: true })`, CC-1.13, by design, for the menu) and
Strike Night's src/index.ts -> shared/index.ts -> shared/physics.ts statically imports
@couchcade/physics (Planck.js) so onTick can step it synchronously every tick. Strike Night is
the first game to use @couchcade/physics, so this is the first time a game's rules module is
heavy enough to blow the eager platform bundle. Verified by `git stash`-ing games/strike-night/
in this same worktree: budgets pass without it, fail with it -- isolated cause, not flaky.
Confirmed there is no way to keep onTick synchronous (required by the CouchcadeGame contract)
while deferring Planck's load past the eager registry import; `hidden: true` doesn't help since
the registry globs every game's JS regardless of the flag.
This is a cross-cutting conflict between three already-approved pieces (CC-3.9 physics package,
CC-1.13 eager registry, and the README.md Performance budgets' 450 KB Platform JS cap, CI-blocking)
that no single games/strike-night file can resolve. Escalated to the orchestrator rather than
guessing at packages/game-sdk or apps/host, which are outside this story's References and are
where CC-3.18 is concurrently working.

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Built Strike Night's rules and state as pure functions per docs/games/strike-night.md (PR #106):
games/strike-night/src/shared/{constants,input,state,physics,rules,view,outcome,snapshot,index}.ts.
init/onPlayerInput/onTick are pure and deterministic (a seeded, unused RNG kept in state per the
game contract's pattern; time only via dtMs and InputContext). onTick steps @couchcade/physics
(Planck.js) during "rolling" with the ball/pin BodyStates, the falling-pin radius/density widening,
the hook push, gutter/pit/settle timing and pin-down rules from the spec's "Ball and pins" section.
The 20 s turn timer, the gentle auto-roll (the bowler's position, speed 0.3, angle 0, spin 0), and
the away-player shortened timer plus input-extension rule (turn flow, rule 7) are implemented.
Current-frame scoring (strike 30, spare 10 + roll 1, open frame) and placements (points, then
strikes, then spares) match owner decision 1 and rule 9. games/strike-night/src/index.ts wires
defineGame with hidden: true (CC-12.6 registers it); src/host/scene.ts and src/controller/* are
scaffold placeholders, minimally adapted to the real types so the package compiles - CC-12.3 and
CC-12.4 own their real content.

test/: contract.test.ts (testGameContract, all 10 checks), rules.test.ts (scoring, turn order,
timer/auto-roll/away, placements/tie-breaks, onPlayerLeft), physics.test.ts (the spec's 5
prototype/tuning-target checks, run for real through the physics), snapshot.test.ts, replay.test.ts
(one recorded 2-player match mixing move/grip/bowl/auto-roll, replays to the exact final state).
42/42 tests pass.

Blocked, then unblocked, on a real cross-cutting issue found during delivery: Strike Night is the

/ 60 KB (PASS). Full repo pnpm check, check:deps, test and build are green.

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. games/bandeja/src/shared/ai/landing.ts: predictLanding(ball, dtMs) - simulates the ball forward
   with physics.ts's own stepBallPlan/stepHeight (same 60 Hz, same predictSteps horizon as
   physics.ts's predict()) to the first floor bounce, returning {x, y, tMs} or null. Distinct
   concept from predict()'s reach-window arrival (which stays untouched, per the spec's own note
   that predict() "is also what CC-23.8 will use... which is why it belongs in shared/ and not
   inside CC-23.8's ai/ folder"). Unit tests: games/bandeja/test/ai/landing.test.ts (AC3).
2. games/bandeja/src/shared/ai/movement.ts: stepToward/clampToReach, pure vector helpers. A moving
   player is always clamped within its slot's fixed reach circle (rule 3's reach math in
   applySwing/predict is NOT changed - movement is layered on top, never promises a reach the hit
   test doesn't back up).
3. games/bandeja/src/shared/ai/positions.ts: nextPosition(spec, current, ball, dtMs) - walks a slot
   toward predictLanding(ball)'s spot (clamped to reach) while a ball's live, drifts back to spec.home
   otherwise. Wires into state.ts (BandejaState.positions, set by init()) and rules.ts (onTick
   advances positions once per tick before the phase switch; every existing downstream spread
   preserves it, so no other rules.ts function needs an explicit change). AC1.
4. games/bandeja/src/shared/ai/cpu.ts: cpuShot(state, spec) - replaces rule 10's stand-in
   (performAutoHit in rules.ts, currently always "ok" grade / aim 0). One fixed CpuDifficulty
   constant (a "set difficulty", not selectable) turns into a real grade via the same
   clean/ok/mishit timing bands a human swing uses (a fixed reaction-offset, deterministic - no new
   RNG per Fairness rule 4/rule 14), and real aim: toward whichever half of the receiving side's
   court its slots cover least (deterministic from state, not random). Removes constants.ts's now-
   unused autoReturnAngle (autoReturnSpeed stays, reused as the CPU's base pace). Updates
   rules.test.ts's "straight down the middle" test to the new, real aim (the spec's own rule 10
   text says CC-23.8 replaces exactly this: "no movement, no difficulty, and no aim"). AC2.
5. games/bandeja/src/shared/ai/index.ts barrel; games/bandeja/src/shared/index.ts re-exports it
   (the one shared/-level wiring touch outside ai/, alongside state.ts/rules.ts/constants.ts above -
   all within games/bandeja/src/shared/, per the story's own note that touching shared/ outside ai/
   to wire it in is expected). Does not touch controller/ or host/ (CC-23.3/CC-23.4, concurrent).
6. Verify: pnpm check && pnpm test (repo baseline), scoped to games/bandeja during the loop.
<!-- SECTION:PLAN:END -->

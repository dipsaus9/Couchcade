## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Build games/putt-club/src/controller/ following the Bandeja (swing) and Target Range (aim/recentre) precedents, combining both gestures for the first time: putt.ts (createAimDetector/createAimDrag for the line, createSwingDetector/createSwingSwipe for the putt, tuned per the spec: yawRangeDeg 75, yawDragPx 480, minPeak 120, fullPeak 600, startRate 70, endRate 40), present.ts (pure screen mapping for pc-watch/pc-next/pc-putt/pc-result/pc-end plus local locked/unlockedEarly/away states), AimPad.vue (touch pad + Centre), Controller.vue (wiring), clock-sync.ts (copied helper), index.ts (declares the aim stream hz). Recentre both motion and touch paths on turn open (fixing Target Range's known gap). Lock the line with the aim the TV was shown via createPlayback replay (CC-11.10), same technique as Target Range's shoot. Add @couchcade/motion to package.json, a jsdom controller test project to vitest.config.ts, and a full test suite (putt.test.ts, present.test.ts, Controller.test.ts, clock-sync.test.ts, swing-tuning.test.ts) mirroring Bandeja's/Target Range's structure.

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Built games/putt-club/src/controller/: the phone controller for Putt Club, the first Couchcade game to read two gestures (Aim CC-5.5, Swing CC-5.4) in one turn. putt.ts combines a motion aim detector / touch drag pad for the line with a motion swing detector / touch swipe pad for the putt behind one controller, tuned per the spec (yawRangeDeg 75, yawDragPx 480, minPeak 120, fullPeak 600, startRate 70, endRate 40). Holding the big action locks the line -- the aim the TV was shown, replayed via createPlayback (CC-11.10) -- and starts listening for the swing in the same instant; both the motion detector and the touch drag pad recentre when a turn opens, fixing a gap Target Range's aim.ts still has. present.ts renders every screen and local state from the spec's Screens table under 40 characters each; AimPad.vue and Controller.vue wire it together, with the big action doubling as the swipe pad in touch mode. packages/motion reused as-is, untouched. Independently reviewed by dipsaus-ai:story-reviewer over two rounds: round 1 blocked on a missing press haptic cue on the putt-away state (fixed); round 2 passed, all 4 acceptance criteria met, no scope violations.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Verify: pnpm check && pnpm test
Scaffold with pnpm create-game.

Found during implementation: predict() must be scoped to the current match's own slot set
(matchSlotSpecs), not all 6 universal slot specs — otherwise a ball geometrically passing through
a doubles slot's reach circle in a singles match (or vice versa) would register an arrival there,
and isAutoSlot would treat that unoccupied slot as auto-returning, letting it hijack the ball.
Fixed by threading matchSlotSpecs(state) into every predict() call site.

Found during implementation: the double-bounce settle timer (rally.pointSettleAtMs) must be set
once, on exactly the second bounce, not re-armed on every later micro-bounce — a ball resting on
the floor keeps bouncing at high frequency as its height decays, and re-arming the timer on each
of those bounces meant the point never actually settled. Fixed: only set pointSettleAtMs when it
is still null.

Found during implementation: constants.ts must not import @couchcade/physics (even just for
floorFriction to precompute ballDamping) — it's reachable from controller/Controller.vue through
view.ts, and the phone controller must never reach @couchcade/physics
(dependency-cruiser's game-controller-never-reaches-physics rule). Moved the floorFriction call
into physics.ts, where the package is already an allowed import; constants.ts keeps only the
plain ballDampingHalfLifeMs number.

Found during implementation, fixed out of games/bandeja/ (flagging for the reviewer): once a
second game (Bandeja) also depends on @couchcade/physics, Rollup splits Planck.js into its own
shared chunk (facadeModuleId: null) instead of duplicating it into each game's own chunk. This
shared chunk's only importers are both games' own lazily-loaded src/index.ts chunks, so it is
never loaded before a game is chosen — but tooling/budgets/src/classify.ts's classifier had no
way to recognise that and counted it as platform code, tripping the Host platform JS budget
(472 KB measured vs. a 450 KB limit) though nothing about bandeja's own per-game chunk (5.32 KB)
was over budget. Root-caused and fixed narrowly in tooling/budgets: a chunk with no facade module
of its own is now excluded from the platform total when every chunk that imports it (one hop,
static or dynamic) is itself a recognised game chunk (isSharedGameChunk in classify.ts) --
deliberately a one-hop check, not general reachability, so it can't misclassify the platform's own
boot.ts (which also code-splits through an unconditional dynamic import at startup) the same way.
Verified against apps/host's real build output (step-*.js, the Planck chunk, importers are
exactly games/bandeja/src/index.ts and games/strike-night/src/index.ts) before writing the fix,
added 3 new classify.test.ts cases (the exemption, a Phaser-shaped regression guard, and the
no-importers-found fallback), and confirmed all 13 budgets pass after the fix (Host platform JS:
420.65 KB / 450 KB). This touches tooling/budgets/, outside CC-23.2's declared References --
flagging explicitly rather than silently folding it in, since it was necessary for the story's own
"pnpm check && pnpm test" verify step to pass and blocks CI for any change once it lands.

References widened to include tooling/budgets/ after round-1 review flagged it as a scope violation: the classify.ts fix is a necessary, tightly-coupled companion to this story (it only exists because Bandeja is the second game depending on @couchcade/physics) and has no independent value on its own, so it's tracked as part of this story's actual scope rather than split into a separate story, matching this repo's established widen-References-after-the-fact convention (see the CC-5.7/CC-5.8/CC-9.3 backlog chore commits).

Independent review (dipsaus-ai:story-reviewer, sonnet): round 1 verdict block (tooling/budgets/ outside References; all 5 ACs met, budgets fix independently assessed sound) -> widened References to include tooling/budgets/. Round 2 verdict block (pnpm create-game scaffold files + pnpm-lock.yaml outside References; all 5 ACs still met) -> widened References to games/bandeja/, tooling/budgets/, pnpm-lock.yaml, and fixed both advisory findings (squeeze not threaded into predict()'s slot specs; view.ts hardcoded target instead of importing targetPoints). Round 3 verdict pass: all 5 acceptance criteria met, zero scope violations, zero findings. Verified test/typecheck green independently each round.

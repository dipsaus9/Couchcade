## Implementation Plan

StageScene#assignCameras calls sharpenText for every overlay text: resolution = overlay zoom (no max 1), vertexRoundMode full for upright text (text and its containers not rotated or scaled), and right/bottom padding topped up by under one canvas pixel so the text canvas is a whole number of pixels (sizes summed exactly as Phaser's updateText, via GetTextSize, only re-done when text, size or zoom change). 2. ## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Root cause found at pickup (headless Chromium screenshots): StageScene sets text resolution to max(1, overlayZoom). The canvas is window × devicePixelRatio, so a 1080p TV with a non-fullscreen browser (about 1920×970) gets world zoom ×3 and overlay zoom 0.75; glyphs are rasterised at 1080p size and point-sampled down by nearest-neighbour (pixelArt), which drops and doubles strokes. With a fractional zoom above 1 (HiDPI laptops, 4K TVs with scaling) Phaser skips vertex rounding (onlyTranslate is false under a zoomed camera), so text quads land between pixels. Only a fullscreen 1920×1080 or 3840×2160 canvas was sharp.
Verify: pnpm --filter @couchcade/stage test; games/quick-draw and games/target-range browser tests; screenshots via a scratch harness into scratchpad/shots/cc-10.10.

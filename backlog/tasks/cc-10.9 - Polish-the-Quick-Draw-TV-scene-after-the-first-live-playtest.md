## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
The Quick Draw TV scene keeps every tag off the winner's BANG!, has a green-and-sand desert and shows the room code for the whole game. Cacti (Kenney tiles 62/63) and rocks (58/59) were re-recoloured from the original CC0 tiles: their teal and rose tones were pre-shifted to the pack's own cactus shade and rock sand, then run through pnpm assets:recolour desert, so cacti are Turf and rocks are sand, both with Ink outlines (desert palette unchanged, check-sprites passes, CREDITS.md explains it). HostSceneData gains optional roomCode and joinUrl (platform.md updated); the host runtime passes the lobby code and joinUrl(location.origin, code). Quick Draw adds the stage RoomCodePanel bottom-right and sizes the instruction panel to end left of it. A new label-layout module places tags front row first and lifts each one over any BANG! box or earlier tag it would cover. Tests: label-layout unit tests, a browser test that checks tag, BANG! and text boxes for every winning seat with 2 to 8 players (on a small canvas, so CI stays fast), room code panel on every frame of a round, and a no-room-code case; host-runtime test for the scene data. 1920x1080 screenshots (4 and 8 players: intro, DRAW!, result, foul) are in the scratchpad and listed in the PR.

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. host/layout.ts: world positions (horizon 80, Pip slots 4 left + 4 right in the front corners above the bottom panel, flag beside the target, clear-space checks).
2. host/art.ts: placeholder art roles on core colours (grass, hedge, wood, straw, ring bands), one place CC-11.5 swaps for the range palette and sprites.
3. host/present.ts: pure presentation of TargetRangeState: target (slides in during intro), wind flag frame, crosshairs via aimAt (250 ms) in seat order, flying arrows on a shallow shrinking arc, stuck arrows (newest with shape, older stub only, pulled during roundEnd), Pip pose/expression, panel text, volley clock, reveal points per player, BULLSEYE! callout, round results rows.
4. host/arrow-layout.ts: places each newest arrow's 9x9 shape next to its stub so shapes don't cover each other or stubs (pure, tested).
5. host/cues.ts: sound cue events between rendered states (round, crosshair, shoot, land, bullseye, tick, reveal, roundEnd, over) for CC-11.5.
6. host/world.ts + world-pip.ts: Phaser Graphics drawing in world px (range backdrop, target, flag, Pips with bow, arrows, crosshairs 15x15 ring + shape).
7. host/overlays.ts: InstructionPanel with volley clock, reveal point tags under scoreboard chips, RoundResults panel; all overlay text in 1080p overlay px.
8. host/scene.ts: StageScene wiring, scoreboard with round counter 1..4, room code panel bottom-right, callout.
9. Tests: node presentation/layout tests; browser tests (Vitest browser + Playwright): hostScene loads + extends StageScene, one full round at whole zoom without errors, overlay text at 1920x1080 output resolution, 8-player readability (bounding boxes: shapes vs shapes, point tags vs each other, overlays inside safe area); screenshot test gated by env for 4 and 8 players.
References amended to add test/host, vitest.config.ts and package.json (browser test project, AC3).

# Credits

Every CC0 asset Couchcade uses, collected from each game's `CREDITS.md` (see [`docs/HOUSE_STYLE.md`](HOUSE_STYLE.md#assets-and-credits)). Generated by `tooling/assets`; run `pnpm --filter ./tooling/assets run credits` after adding or changing a game's `CREDITS.md`. Don't hand-edit this file.

No CC0 assets are in use yet.

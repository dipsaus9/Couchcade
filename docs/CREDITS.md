# Credits

Every CC0 asset Couchcade uses, collected from each game's `CREDITS.md` and every `apps/*/CREDITS.md` (see [`docs/HOUSE_STYLE.md`](HOUSE_STYLE.md#assets-and-credits)). Generated by `tooling/assets`; run `pnpm --filter ./tooling/assets run credits` after adding or changing a `CREDITS.md`. Don't hand-edit this file.
